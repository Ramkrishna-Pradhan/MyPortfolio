A dynamic, full-stack personal portfolio website built to showcase my projects, technical skills in web development and machine learning, and professional resume. Unlike a standard static site, this portfolio features a custom PHP backend and database integration for managing content and processing contact requests.

## ✨ Key Features

*   **Comprehensive Showcase:** Includes structured, dedicated pages for About, Resume, Services, and Contact details.
*   **Secure Backend Admin Panel:** Custom PHP scripts (`login.php`, `adminer.php`) allow for secure backend access to manage portfolio data.
*   **Database Integration:** Full CRUD (Create, Read, Update, Delete) capabilities to dynamically update and delete site records (`update.php`, `delete.php`).
*   **Dynamic Contact Form:** Handles user inquiries and messages seamlessly through the backend (`contact.php`).
*   **Modular & Responsive UI:** Clean, maintainable styling with dedicated CSS files for every section (e.g., `resume.css`, `about.css`, `navbar.css`) to ensure it looks flawless on any device.

## 🛠️ Tech Stack

*   **Front-End:** HTML5, CSS3 (Modular Architecture), Vanilla JavaScript (`home.js`, `navbar.js`)
*   **Back-End:** PHP
*   **Database:** MySQL (managed via `db.php`)
*   **Visual Assets:** Features custom technology icons highlighting proficiencies in PHP, JS, HTML, CSS, Databases, and WordPress.

## 📂 Project Structure

```text
├── css/        # Section-specific stylesheets (home, about, contact, adminer, etc.)
├── html/       # Front-end structural templates and pages
├── img/        # Profile images, banners, and tech stack icons
├── js/         # Client-side interactivity and navigation logic
├── php/        # Backend logic, DB connection, authentication, and CRUD operations
└── README.md   # Project documentation
```
